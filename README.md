# 台灣交通儀表板 Taiwan Mobility Atlas

整合台灣飛航、台鐵及台灣高鐵資訊的互動式儀表板，支援進階篩選、車站及站間車次查詢，以及可安裝的 PWA 介面。

**[開啟台灣交通儀表板](https://nistd1023.github.io/taiwan-mobility-atlas/)**

## 使用方式

使用支援 JavaScript 的現代瀏覽器開啟網站。首次使用可先瀏覽「示範資料」；如需查詢 TDX 資料，請依照下方步驟取得金鑰並完成連線。

### 一、註冊 TDX 並取得 API 金鑰

1. 前往交通部 [TDX 運輸資料流通服務](https://tdx.transportdata.tw/)，選擇註冊會員，依網站指示完成註冊及必要的驗證，然後登入。
2. 登入後進入 **會員中心 → 資料服務 → API 金鑰**，依畫面指示建立或查看金鑰。
3. 複製該組金鑰中的 **Client ID** 與 **Client Secret**，供儀表板連線使用。兩者是同一組憑證，請分別填入對應欄位。
4. 確認帳號可使用所需資料服務；查詢額度、存取頻率、服務類別及可能的費用依 TDX 當時的方案與規定為準，有需要時再依用量訂閱。

詳見 TDX 官方的[服務使用流程](https://tdx.transportdata.tw/about/service)與[線上 API 說明](https://tdx.transportdata.tw/api-service/swagger/basic/)。

### 二、在儀表板設定連線

1. 開啟[儀表板](https://nistd1023.github.io/taiwan-mobility-atlas/)，在飛航、台鐵或高鐵頁面上方點選 **⚙ 資料連線**。
2. 分別貼上 TDX 的 **Client ID** 與 **Client Secret**。
3. 可按 **儲存金鑰**，接著按頁面對應的連線按鈕：
   - 飛航：**連接即時資料**
   - 台鐵：**連接 TDX 台鐵資料**
   - 高鐵：**連接 TDX 高鐵資料**
4. 連線成功後，頁面會顯示 TDX 資料來源與取得狀態；若尚未連線，則顯示「示範資料」。實際資料仍以畫面的取得狀態及各營運單位公告為準。

飛航、台鐵與高鐵共用同一網站、同一瀏覽器內儲存的金鑰與更新設定。不同瀏覽器、裝置或不同網站網址的設定不會互通，需各自設定。

### 三、更新頻率與資料範圍

- 頁面提供「自動」與「手動」更新模式；在「資料連線」視窗可設定自動更新間隔，預設 **60 分鐘**，可輸入 **1–1440 分鐘**後按「儲存間隔」。
- 各頁依所需資料分別查詢 TDX。切換或開啟已連線頁面時，即使選擇手動更新也會查詢一次；多個頁面同時開啟會分別查詢。更新過於頻繁可能消耗較多查詢額度。
- 飛航資料為機場航班資訊，非飛機即時定位；台鐵車站動態可能只涵蓋部分車次，沒有資料不代表準點。
- 高鐵頁面查詢時刻表與營運通阻公告；**目前未接入逐車即時到離站及誤點資料**，請以高鐵公告為準。
- 離線時僅提供已快取的網站介面，無法取得即時資料。

### 四、金鑰安全與常見問題

- 金鑰儲存在目前裝置的瀏覽器本機儲存空間，**未加密**；同一網站的其他程式或瀏覽器擴充功能可能讀取，請勿在共用或不信任的裝置儲存。
- 請勿將 Client ID、Client Secret、存取權杖或含憑證的截圖提交至公開儲存庫、README 或分享給他人。
- 如需移除金鑰，在「資料連線」視窗按 **清除本機金鑰**；這也會停止同一瀏覽器中各開啟頁面的即時資料連線。也可按「使用示範資料」切換回示範模式。
- **無法連線或驗證失敗**：確認兩個欄位沒有貼錯或多餘空白，並至 TDX 確認金鑰有效、帳號權限與額度。若顯示網路或跨網域錯誤，請檢查網路、瀏覽器限制及 TDX 服務狀態後重試。
- **部分資料未顯示**：確認查詢日期、車站及資料來源狀態；資料供應、權限、查詢次數與更新時間都可能影響結果。
- **顯示示範資料**：檢查是否已完成連線，或曾切回示範模式；開啟「資料連線」重新連接。

## 本機執行

在本目錄執行 `python3 -m http.server 8000`，然後使用瀏覽器開啟 `http://localhost:8000/`。Service Worker 需要 HTTPS 或 localhost 安全環境。

## 專案結構

- `index.html`、`app.js`：飛航資訊。
- `train.html`、`train.js`、`train.css`：台鐵資訊。
- `thsr.html`、`thsr.js`：台灣高鐵資訊。
- `transport-core.js`、`map-interactions.js`、`style.css`：共用資料與介面功能。
- `manifest.webmanifest`、`pwa.js`、`service-worker.js`、`icons/`：PWA 設定與離線介面。

網站資料可能有延遲或異動；請勿將儀表板顯示視為即時營運資訊的唯一依據。
